# 01 · 定位与市场 【提案】

## 一句话定位

**网文翻译工作室的产能引擎**：不是"又一个 AI 翻译"，而是让连载翻译在 300 章后
依然术语一致、人物不崩、文风不漂，并把人工校对压缩成抽检。

## 市场背景（2026-10）

- 网文出海是成熟现金流市场：WebNovel（起点国际）、GoodNovel 等平台持续收稿，
  中文→英/西/葡语需求量最大；
- AI 冲击下平台稿费承压，翻译从业者（工作室模式：1 主持稿+N 译员）的生存策略
  从"比质量"变成"用 AI 提效保质量"——**工具付费方是工作室主，决策逻辑是产能经济学**；
- 通用翻译（DeepL/ChatGPT）处理单章尚可，连载一致性（术语漂移、人物状态错乱、
  文风漂移）无解——这是全部差异化所在。

## 目标用户

| 层 | 用户 | 场景 | 付费逻辑 |
|---|---|---|---|
| P0 | 翻译工作室（3-20 人，月产 50-300 万字） | 平台签约连载的多语种产出 | 一致性返工与断更罚金 >> 工具费 |
| P1 | 独立网文译者 | 个人接单提效 | 月订阅（对价格敏感，走低价档） |
| P2 | 出海原创作者（中文写作直接发海外平台） | 自译自发 | 小众，v1 观察 |

## 竞品格局（2026-10 查证）

| 竞品 | 形态 | 弱点（=我们的空档） |
|---|---|---|
| DeepL / ChatGPT / Skywork 等通用翻译 | 按次/订阅 | 无连载记忆：术语表靠人维护、人物状态无追踪、文风漂移 |
| Webnovels AI（专用工具，早期） | 网文翻译 SaaS | 早期产品，一致性引擎深度与抽检工作台欠缺；工作室工作流（多人协作/交付格式）未覆盖 |
| CAT 工具（Trados/LingoHub 类）+ LLM 自拼 | 专业译者的自组装 | 翻译记忆是句级对齐，不懂"剧情"；组装维护成本高，工作室主没工程能力 |
| 平台自带 AI 辅助（WebNovel 内部工具） | 平台内 | 只服务平台签约，格式锁定，非平台渠道用不了 |

**空档总结**："工作室级一致性引擎 + 抽检工作台"组合无人占住；客户集中（工作室社群）、
决策链短（老板一人拍板）、ROI 可当场计算（返工率/产能倍数）。

## 定价（提案，按产能）

| 档 | 价格 | 内容 |
|---|---|---|
| 免费 | 5 万字/月 | 全功能试用 |
| 独立译者 | ¥99/月 | 50 万字/月 + 单人工作台 |
| 工作室 | ¥599/月 | 500 万字/月 + 多人协作 + 术语库托管 + API |
| 企业 | 议价 | 私有化（模型不出门——部分工作室有保密协议约束） |

锚点：译员成本约 ¥30-60/千字，工具把 AI 初校 + 人工抽检的混合成本压到 ¥5-10/千字，
工作室月产 100 万字省下的就是每月 2-3 万元——¥599 定价是零头。

## 分发

1. 工作室试点（外部依赖已列 roadmap）：1-2 家免费换案例与语料授权；
2. 网文译者社群（QQ 群/贴吧/龙的天空）发一致性对比 demo（同一段 300 章前后术语表变化，
   视觉冲击即营销）；
3. 与出海平台的中介/培训机构合作分佣。

## kill 准则

- 6 周内 <10 个译者/工作室真实跑过 ≥3 章流水线 → 冻结；
- 12 周内 <3 个付费 → 冻结；一致性评测基准（见 03）独立开源发布。

## 版权红线（M0 拍板）

工具只处理用户自有版权/已授权稿件；不建公开语料库；试点语料需书面授权；
评测集用公版小说（古典名著、版权过期作品）自制——规避一切侵权面。
